QUICK CALL GUIDE

从页面、脚本或终端调用 localstore

把它当成一块只在本机运行的 HTTP 键值存储。默认地址就是当前服务的监听地址。

BASE URL http://127.0.0.1:7777
BROWSER

浏览器 fetch

写入 JSON，再从另一个页面读取同一个 key。

const base = "http://127.0.0.1:7777";
const key = encodeURIComponent("user settings");

await fetch(base + "/mock/" + key, {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ theme: "dark" }),
});

const value = await fetch(base + "/mock/" + key)
  .then((response) => {
    if (!response.ok) throw new Error("HTTP " + response.status);
    return response.json();
  });
CURL

终端调用

适合快速写入、读取或清理一条调试数据。

# 写入 JSON
curl -X POST 'http://127.0.0.1:7777/mock/user' \
  -H 'Content-Type: application/json' \
  --data '{"name":"Alice","enabled":true}'

# 读取
curl --fail 'http://127.0.0.1:7777/mock/user'

# 删除
curl -X DELETE 'http://127.0.0.1:7777/mock/user'
POST

自定义成功 / 错误响应

调用方先注册两套返回模板，再用 `?response=success` 或 `?response=error` 选择返回格式；不带参数仍读取原始值。

# 注册成功和错误返回格式
curl -X POST 'http://127.0.0.1:7777/mock/user/responses' \
  -H 'Content-Type: application/json' \
  --data '{
    "success": {
      "status": 200,
      "body": { "code": 0, "data": {} }
    },
    "error": {
      "status": 429,
      "headers": { "content-type": "application/json" },
      "body": { "code": 429, "message": "rate limited" }
    }
  }'

# 按场景读取错误格式
curl 'http://127.0.0.1:7777/mock/user?response=error'
POST/mock/:key写入原始值
GET/mock/:key读取原始值或模板
POST/mock/:key/responses注册响应模板
GET/keys列出全部 key
DELETE/mock/:key删除指定值

调用提示 模板支持自定义 HTTP 状态码、响应头和 JSON/文本 body；键名包含空格或斜杠时先使用 encodeURIComponent(key)。浏览器跨端口调用已内置 CORS 和预检支持，这个服务面向本机开发，不用于生产数据。
