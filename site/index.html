WHY LOCALSTORE

当状态藏在浏览器里，调试就被困在一个标签页。

你正在调试的，可能是另一个页面、另一个端口，甚至是另一个进程。localstore 提供一块中立的本地空间，让这些上下文用同一个 key 交换数据。

THE SMALL TOOL THAT STAYS OUT OF THE WAY

把复杂留给应用，
把存取变成一条请求。

↗01

任意来源都能读写

内置 CORS，跨页面、跨端口、跨进程共享调试数据，不用再复制粘贴。

≋02

原样保存你的值

文本、JSON、配置片段都按原始内容保存，同时记住写入时的 Content-Type。

⌁03

每一次请求都可见

启动后打开本地控制台，实时查看读写轨迹、状态码、来源和耗时。

READY WHEN YOU ARE

从启动服务到第一次读写，只要三行。

不需要 SDK，不需要构建插件。localstore 是一个可以随手启动、随时关掉的开发工具。

01
启动npm start
02
写入POST /mock/:key
03
观察GET /logs
quick-start.js
const key = encodeURIComponent("user settings");

await fetch(`http://127.0.0.1:7777/mock/${key}`, {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ theme: "dark" }),
});
